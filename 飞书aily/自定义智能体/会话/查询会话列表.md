# 查询会话列表

本接口用于查询智能体的会话列表。

## 请求

基本 | &nbsp;
---|---
HTTP URL | https://open.feishu.cn/open-apis/aily/v1/agents/:agent_id/sessions
HTTP Method | GET
接口频率限制 | [特殊频控](https://open.feishu.cn/document/ukTMukTMukTM/uUzN04SN3QjL1cDN)
支持的应用类型 | Custom App
权限要求<br>**调用该 API 所需的权限。开启其中任意一项权限即可调用** | 获取团队智能体的对话内容(aily:agent_chat:read)

### 请求头

名称 | 类型 | 必填 | 描述
---|---|---|---
Authorization | string | 是 | `tenant_access_token`<br>或<br>`user_access_token`<br>**值格式**："Bearer `access_token`"<br>**示例值**："Bearer u-7f1bcd13fc57d46bac21793a18e560"<br>[了解更多：如何选择与获取 access token](https://open.feishu.cn/document/uAjLw4CM/ugTN1YjL4UTN24CO1UjN/trouble-shooting/how-to-choose-which-type-of-token-to-use)

### 路径参数

名称 | 类型 | 描述
---|---|---
agent_id | string | 智能体ID，通过智能体后台详情的地址栏中获取<br>**示例值**："agent_4k4ue29hpwrx2"

### 查询参数

名称 | 类型 | 必填 | 描述
---|---|---|---
page_size | int | 否 | **示例值**：10
page_token | string | 否 | 分页标记，第一次请求不填，表示从头开始遍历；分页查询结果还有更多项时会同时返回新的 page_token，下次遍历可采用该 page_token 获取查询结果<br>**示例值**：eVQrYzJBNDNONlk4VFZBZVlSdzlKdFJ4bVVHVExENDNKVHoxaVdiVnViQT0=

## 响应

### 响应体

名称 | 类型 | 描述
---|---|---
code | int | 错误码，非 0 表示失败
msg | string | 错误描述
data | \- | \-
sessions | agent_chat_session\[\] | 会话列表
session_id | string | 会话ID
name | string | 会话名
status | string | 会话状态
created_at | number(float) | 创建时间
last_chat_at | number(float) | 最后一次对话时间
has_more | boolean | 是否还有更多项
next_page_token | string | 下一页的token

### 响应体示例
```json
{
    "code": 0,
    "msg": "success",
    "data": {
        "sessions": [
            {
                "session_id": "conversation_sadcadcds2",
                "name": "question",
                "status": "done",
                "created_at": 1783428305028,
                "last_chat_at": 1783428305028
            }
        ],
        "has_more": true,
        "next_page_token": "1783425184259422"
    }
}
```

### 错误码

HTTP状态码 | 错误码 | 描述 | 排查建议
---|---|---|---
400 | 2700001 | param is invalid | 检查参数是否正确
